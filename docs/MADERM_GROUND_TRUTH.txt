Script-visible state mapping
----------------------------
The wrapper translates the ReelMagic/FMP driver state rather than exposing the
raw bitfield directly:

- raw state bit 0x01 -> MADE state 2, Paused
- otherwise raw & 0x14 -> MADE state 1, Playing
- otherwise -> MADE state 0, Closed/Stopped

PlayMpegMovie behavior
----------------------
Layer argument:

- argv[0] == 2 -> command 09h / subfunction 040Eh / Z-order 2, MPEG over VGA
- argv[0] != 2 -> Z-order 4, MPEG under VGA

Playback-mode argument:

- argv[1] == 2 -> Play low subfunction 4, looping playback
- otherwise -> Play low subfunction 1, pause on completion
- argv[1] == 3 additionally blocks until the script-visible state is no longer Playing

External 106
------------
External 106 only acts when the script-visible state is Paused.

The wrapper:

1. reads command 0Ah / parameter 0208h user data;
2. issues command 03h with 0301h or 0304h;
3. returns MADE true, value 1.

The ReelMagic driver masks the Play subfunction with 0x000F, so these values
correspond to resume-once and resume-loop behavior.

Palette and compositing
-----------------------
MADERM initialization sets ReelMagic parameter 040Dh to 0 before opening RTZ
streams. This supports palette index 0 as the transparent/alpha VGA index used
when MPEG is behind the VGA surface.
