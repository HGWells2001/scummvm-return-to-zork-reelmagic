# Zero Comico / ScummVM - Stage 21\n\nStage 21 begins reconstructing the retail room/portal topology from `room.isc` using the serializer strings embedded in the original executable.\n\nBranch: `scratch/zerocomico-stage21`.\n\n## Ground truth from the executable\n\nThe retail executable exposes these Room output formats:\n\n```\nPrefix: %s\nbackgrd: "%s"\nobjects: "%s"\nportal: %s %s %s "%s" %s\nmap: %s\ncameramap: %s\ncamera: %s\ncameraspot: %s\n```\n\nIt also reports errors that reference a portal and a room independently, proving that room/portal post-linking occurs after parsing.\n\n## RoomTopologyParser\n\nThe parser records the proven Room fields and preserves each portal as exactly five source fields. Quoted field 4 is kept as one string even when it contains spaces.\n\nA portal with a different arity is rejected instead of silently reshaping it.\n\n## Topology resolution without field-order guesses\n\n`RoomPortalTopologyResolver` does not assume which of the five portal fields is the target Room or the Portal shape.\n\nInstead it compares every field exactly against:\n\n- declared `Room` names;\n- `Shape.shp` entries whose type is explicitly `Portal`.\n\nIf exactly one field matches a different Room, the resolution exposes one Room candidate. If exactly one field matches a Portal shape, it exposes one shape candidate.\n\nIf two fields match Room names, the portal remains ambiguous. Nothing is chosen by position or order.\n\nThis gives the engine useful topology evidence while preserving the remaining reverse-engineering boundary.\n\n## Why this matters\n\nThe path from the first Mp1 room toward real room changes is now:\n\n```\nroom.isc Room\n  -> map / cameramap / camera / cameraspot\n  -> portal five-field record\n  -> exact Room-name correlation\n  -> exact Portal-shape correlation\n  -> future proven field semantics\n  -> room transition runtime\n```\n\n## Validation\n\nThe focused test covers:\n\n- CRLF Room parsing;\n- Prefix/background/objects/map/camera fields;\n- exact five-field portal parsing;\n- quoted portal field preservation;\n- unique Room correlation;\n- unique Portal-shape correlation;\n- deliberate ambiguity when two Room names appear;\n- malformed portal arity rejection;\n- `//` inside quoted text versus a real inline comment.\n\nCI syntax-checks Stages 6 through 21 with `-Werror`, builds ScummVM's real `libcommon`, runs the Stage 21 topology test and packages all current modules.\n
