# Zero Comico / ScummVM - Stage 23\n\nStage 23 prepares the two different navigation plans declared by a retail Room: `Map` for actors and `MapCam` for camera movement.\n\nBranch: `scratch/zerocomico-stage23`.\n\n## Retail evidence\n\nThe BSP corpus proves that `Map` and `MapCam` are distinct systems:\n\n- `Map` describes where the character may walk;\n- `MapCam` describes where the camera may move;\n- some pairs are byte-identical;\n- others differ greatly;\n- two shipped `MapCam` files are exactly zero bytes.\n\nTherefore an empty camera map is valid retail data, while an empty actor walk map is not treated as a normal navigable Room.\n\n## PreparedRoomNavigation\n\nThe Stage 23 bundle contains:\n\n- target Room name;\n- resolved actor Map path;\n- parsed actor `BspNavigation`;\n- optional resolved camera MapCam path;\n- parsed camera `BspNavigation` when non-empty;\n- explicit flags for declared/empty/available camera navigation.\n\n`Map` and `MapCam` are never merged.\n\n## Resource paths\n\n`roomBspResourcePath()` normalizes MainPlace names, preserves explicit relative paths and adds `.bsp` only when absent.\n\nRoom resource names such as `r12_Map00` therefore resolve to `Mp1/gameplay/r12_Map00.bsp` without hardcoding a specific Room.\n\n## Transactional Stage 22 integration\n\n`RoomNavigationTransitionHost` implements the Stage 22 transition host.\n\nIt performs:\n\n```\nresolved portal transition\n  -> load + parse target actor Map\n  -> load target MapCam\n       -> parse if non-empty\n       -> mark unavailable if retail zero-byte file\n  -> ask scene/backend to activate the prepared Room\n  -> commit navigation only after backend success\n```\n\nA backend rejection leaves the last committed Room navigation untouched.\n\n## Fidelity boundary\n\nStage 23 still does not invent camera projection or movement policy. It only supplies the proven camera walkable plan independently from the actor plan.\n\n## Validation\n\nThe executable test verifies:\n\n- BSP path normalization;\n- independent actor and camera graphs;\n- declared zero-byte MapCam acceptance;\n- missing MapCam declaration acceptance;\n- empty/missing actor Map rejection;\n- missing declared MapCam rejection;\n- transactional activation rollback.\n\nCI syntax-checks Stages 6 through 23 with `-Werror`, builds ScummVM's real `libcommon`, runs the Stage 23 test and packages the full module set.\n
