# Zero Comico / ScummVM - Stage 22\n\nStage 22 mainline turns the conservative Stage 21 portal evidence into a transactional room-transition graph while preserving the full green Stage 6–21 history.\n\nBranch: `scratch/zerocomico-stage22-mainline`.\n\n## Resolved transitions\n\nA transition is created only when a Stage 21 portal record has:\n\n- exactly one exact match to a different declared Room;\n- exactly one exact match to a Shape.shp entry of type Portal.\n\nIf either side is ambiguous, the portal is omitted from the executable transition graph.\n\nNo portal field position is assumed. The resolver still does not claim that field 1 or field 2 has a particular meaning.\n\n## Target-room resource bundle\n\nEvery resolved transition copies the proven resource fields from the destination Room:\n\n- Prefix;\n- background;\n- objects;\n- map;\n- cameramap;\n- camera;\n- cameraspot.\n\nIt also preserves all five raw portal fields.\n\nIf Stage 19 has numeric A/B data for the Portal shape, that geometry is attached to the descriptor without assigning crossing-direction semantics.\n\n## Transactional runtime\n\n`RoomTransitionRuntime::activatePortal()` looks up a transition by the current Room plus the activated Portal shape.\n\nThe engine host receives the full descriptor and must validate/load the destination resources transactionally.\n\nThe runtime changes `currentRoom` only after the host returns success.\n\nA failed target load leaves the previous Room active.\n\n## What remains deliberately unresolved\n\nStage 22 still does not infer:\n\n- which A/B endpoint is the entry or exit side;\n- portal crossing direction;\n- which portal field encodes entry helper versus visibility set;\n- BSP-to-P3D coordinate mapping;\n- camera projection details.\n\nThose boundaries remain outside the transition graph until grounded by retail evidence.\n\n## Validation\n\nThe executable self-test covers:\n\n- bidirectional Room1_1 / Room1_2 transitions;\n- target map/cameramap/camera/cameraspot propagation;\n- optional numeric Portal A/B geometry;\n- case-insensitive lookup;\n- host rejection rollback;\n- unknown Portal no-op;\n- ambiguous target Room exclusion;\n- operation without numeric Portal geometry.\n\nCI syntax-checks Stages 6 through 22 with `-Werror`, builds ScummVM's real `libcommon`, executes the Stage 22 transition test and packages the full experimental module set.\n
