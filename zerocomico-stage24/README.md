# Zero Comico / ScummVM - Stage 24\n\nStage 24 connects the room-transition stack to the live `GameplayMainPlaceState` used by Giovanni's pathfinding runtime.\n\nBranch: `scratch/zerocomico-stage24`.\n\n## Why this is the first real gameplay Room swap\n\nEarlier stages could resolve a portal, prepare the target Map/MapCam and ask a renderer to activate a target Room.\n\nStage 24 commits that result into the same state object already referenced by `GameplayRuntime`.\n\nOn success:\n\n```\nportal activation\n  -> Stage 22 resolved target Room\n  -> Stage 23 loads target Map + MapCam\n  -> renderer/scene host activates target Room\n  -> GameplayMainPlaceState.activeRoom = target\n  -> GameplayMainPlaceState.navigation = target actor Map\n  -> RoomTransitionRuntime.currentRoom = target\n```\n\nSubsequent pathfinding therefore reads the new Room's BSP automatically.\n\n## Transactionality\n\n`GameplayRoomStateActivation` copies the target Room descriptor and actor BSP, but does not publish them until the renderer-side activation succeeds.\n\nIf:\n\n- the target actor Map cannot be loaded;\n- the declared MapCam cannot be loaded;\n- BSP parsing fails;\n- or the renderer refuses the target Room;\n\nthen active Room, current transition Room and the actor navigation graph remain unchanged.\n\n## No new portal semantics\n\nStage 24 still activates a portal by its already resolved Shape name. It does not infer crossing direction, A/B endpoint roles or which raw portal field represents the entry side.\n\n## Validation\n\nThe focused executable test uses two Rooms with different BSP graph sizes and verifies:\n\n- successful Room1_1 -> Room1_2 changes activeRoom and actor navigation together;\n- camera navigation reaches the scene host;\n- renderer rejection rolls back all gameplay state;\n- target BSP load failure occurs before scene activation;\n- reverse Room1_2 -> Room1_1 restores the first BSP;\n- unknown portals leave the state untouched.\n\nCI syntax-checks Stages 6 through 24 with `-Werror`, builds ScummVM's real `libcommon`, runs the Stage 24 integration test and packages all modules.\n
